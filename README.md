# 🚤 ESP32-S3 RC Boat

A DIY lightweight RC boat built around an **ESP32-S3** and a custom-made motor driver.  
The propulsion system uses a **720 coreless DC motor**, powered by a **3.7V Li-Po battery**, with a **31 mm 3-blade propeller**.

The motor driver is self-made using an **AO3400 MOSFET, SS14 diode, 10kΩ resistor, and capacitor** for improved power stability.

## 🧠 ESP32-S3 Controller

The **ESP32-S3** is used as the main controller of the RC boat.

It handles the control signals and controls the 720 coreless motor through the custom-built MOSFET motor driver.

The ESP32-S3 was designed to operate with a stable power supply, so a capacitor is placed at its power input to help reduce voltage fluctuations and disturbances caused by the motor.

---

## 💻 Software & Programming

The **ESP32-S3** was programmed using **ESP LaunchPad**.

The required firmware/code was uploaded to the ESP32-S3 through ESP LaunchPad to control the RC boat and operate the motor through the custom-built motor driver.


## ⚡ Custom Motor Driver

One of the main features of this project is the **self-made motor driver**.

Instead of using a commercially available motor driver module, the motor is controlled using a discrete **AO3400 MOSFET circuit**.

### Motor Driver Components

- **AO3400 MOSFET**
  - Used as the main electronic switch for controlling the motor.

- **SS14 Schottky Diode**
  - Used for protection against voltage spikes/back-EMF generated by the DC motor.

- **10kΩ Resistor**
  - Used for MOSFET gate control.

- **Capacitor**
  - Connected at the ESP32-S3 power input.
  - Helps stabilize the power supply and reduce disturbances caused by sudden motor current changes.
